How to Open or Install ClassSummariser

Quickest

Zero-Download Browser Access

ClassSummariser is live and hosted on GitHub Pages. You can run it instantly on any device with no installation required.

  1. Open the link: https://gorgioalahmar.github.io/class-summariser/
  2. Bookmark the page (⌘ + D on Mac or Ctrl + D on Windows) for one-click access during lectures.
  3. Paste your lecture dictation or click "Live Mic" to record speech.

Install as a Desktop App

Launch ClassSummariser in its own dedicated, distraction-free window directly from your macOS Dock or Windows Start Menu.

  1. Step 1: Open the app in Google Chrome or Microsoft Edge.
  2. Step 2: Look on the right side of the address/URL bar and click the Install icon ⊕.
    Or click Chrome's menu (three dots ⋮) > "Save and share" > "Install ClassSummariser PRO".
  3. Step 3: Click Install in the confirmation box.
  4. Step 4: You can now launch ClassSummariser from your Mac Launchpad, Applications folder, or Windows Start Menu!

Install on iPhone, iPad or Android

🍎 iPhone / iPad (Safari)
  1. Open the site in Safari.
  2. Tap the Share button (box with arrow ⎋ at bottom).
  3. Scroll down and tap "Add to Home Screen".
  4. Tap Add. It now acts like a native iOS app!
🤖 Android (Chrome)
  1. Open the site in Chrome.
  2. Tap the menu icon (three dots ⋮).
  3. Tap "Install app" or "Add to Home screen".
  4. Tap Install to add it to your apps.

Run Locally on Your Machine (100% Offline)

ClassSummariser has zero external build dependencies. You can run it offline on your laptop:

Option A: Direct Double-Click (No Git Required)
  1. Go to github.com/gorgioalahmar/class-summariser
  2. Click the green "<> Code" button and click "Download ZIP".
  3. Unzip the downloaded folder and double-click index.html. It will open in your browser immediately!
Option B: Terminal (Git) 
git clone https://github.com/gorgioalahmar/class-summariser.git
cd class-summariser
open index.html   # On macOS (or: start index.html on Windows)
